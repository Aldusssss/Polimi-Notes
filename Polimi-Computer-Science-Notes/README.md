# Polimi-Computer-Science-Notes

**Course Content Structure**

The notes are organized into 5 main macro-areas, covering the fundamentals of computer science from the first C++ programs to data structures, object-oriented programming and system programming. These notes are based on lectures from the first-year Computer Engineering course at Politecnico di Milano.


## **[01 — Programming Fundamentals and C++ Basics](./Lessons-1)**
(Modules 1-9)

<details>
<summary>Main topics</summary>

<br>

- Algorithms, flow charts and stepwise program design
- Variables, identifiers and the basic structure of a computer
- Binary data representation (bits, integers, floating point, ASCII, bytes)
- Translation of a source program into machine language
- Input/output with `cin` and `cout`
- Control structures (`while`, `do-while`, `for`, `if-else`)
- Comments, indentation and program readability
- Robustness and testing

## **[05 — Trees, Classes and System Programming](./Lessons-5)**
(Modules 31-42)

<details>
<summary>Main topics</summary>

**Trees and Classes:**
- Binary search trees (search, insertion, deletion, balancing)
- Classes in C++ (encapsulation, constructors, friend classes)
- Tree traversals (in-order, pre-order, post-order)
- Operator overloading

**System Programming:**
- Operating systems, processes and the scheduler
- File management in C (`fopen`, `fseek`, `fread`, `fwrite`)
- Formatted I/O in C (`printf`, `scanf`, `sprintf`, `sscanf`)
- Process management (`fork`, `wait`, `exec`, `exit`)
- Command-line parameters (`argc`, `argv`)
