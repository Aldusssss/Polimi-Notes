# Notes

Course notes from the first year of Computer Engineering at Politecnico di Milano, collected in one place. Each subject lives in its own folder, with its own README that lists the macro-areas and the lessons.

## Subjects

### [Polimi-Economics-Notes](./Polimi-Economics-Notes)

Business economics: the firm and corporate governance, strategy and organization, financial statements, financial ratio analysis, managerial accounting and investment evaluation.

### [Polimi-Computer-Science-Notes](./Polimi-Computer-Science-Notes)

Computer science fundamentals: programming in C++, functions and recursion, arrays, records, pointers and linked lists, binary search trees and classes, and system programming in C.
